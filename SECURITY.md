# Security Policy

## Reporting a vulnerability

Please do not disclose security issues publicly until they have been evaluated and addressed.

Send vulnerability reports to the project maintainer via a private channel or designated security contact.

Include:

- the affected component or version
- a clear reproduction or trigger
- impact assessment
- any suggested mitigation

## Response expectations

We aim to acknowledge reports promptly and provide a remediation plan where feasible.

## Supported versions

The project is currently maintained in its main branch and should be treated as the supported line for security review.
