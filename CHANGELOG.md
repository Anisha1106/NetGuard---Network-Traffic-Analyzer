# Changelog

All notable changes to this project will be documented in this file.

- benchmark runner
- sample PCAP generator
- CI workflow and container build support

### Changed

- Standardized project structure and developer tooling
- Added installation metadata and packaging support

### Fixed

- Clean build path handling for local and CI environments
- Reproducible project setup across developer machines
